What this guide does not do

Source-grounded, not automatically verified

A framework describes principles. An Engineering statement describes a proposed or reported implementation. Neither is proof that the safeguard operates.

This V2 prototype uses a transparent rule-based matrix; it cannot assess arbitrary source code or determine real-world effectiveness. For a real environment, professional investigation remains necessary.
