01 / ORIENT · Overview

The same approval can mean three different things.

AI can review code, execute a human’s decision, or make a decision under delegated policy. A GitHub approval event looks similar in each case. The authority behind it is not.

The question

Before debating AI accuracy or SOX requirements, ask: who actually decided, who acted, and what stops an action outside that authority?

This is an architectural distinction, not an assumption that human review is always superior.

DECISION TAKEAWAY

The object in GitHub is an action record. Authorization depends on who made the decision, the effective policy, and the constraints that actually enforced it.

THE METHOD

Start with the problem, then design the authority.

A productive engineering conversation begins by identifying the bottleneck: delayed review, weak code ownership, inconsistent judgments, or a costly approval ceremony. Those are different problems. An autonomous approver is one possible solution, not the default.
