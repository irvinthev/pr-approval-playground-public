Gate 1 — Eligibility

Rules establish which changes may be considered for automation.

An AI score should not expand the eligible population.

Gate 2 — Authorization

A controlled identity approves an eligible change under an enforceable policy.

Model accuracy alone does not confer authority.

Gate 3 — Integrity

Approved source should trace through the build to the deployed artifact.

Version monitoring cannot prove code correctness.
