How this first slice works

This experience accepts open-ended text. It does not yet use an LLM to interpret novel architectures. A transparent rule matcher retrieves candidate topics and existing catalog provisions; unsupported aspects stay unknown.

Evidence boundary
A framework reference can inform a safeguard. It does not establish the applicable requirement, an implemented control, or evidence that an actual change is authorized.

Source discipline

  • One canonical source catalog, no copied framework records.
  • Provision ID, publisher link, version and qualification displayed together.
  • Human-readable uncertainty and no fabricated compliance status.
  • Generic scenarios and local-only input.

What comes after this?

Add a controlled LLM layer to interpret unfamiliar scenarios, retrieve applicable provisions, generate counterexamples and maintain explicit scenario state. Its output must be validated against catalog IDs and clearly differentiated from deterministic checks.
